# Снятые ограничения: тестовые документы

| Файл | Что проверяет |
|---|---|
| bidi.docx | лам-алеф, зеркальные скобки в RTL, RLE/PDF, `w:bdo`, изолят RLI/PDI, числа и проценты в иврите |
| vml.docx | VML: шаблоны `v:shapetype` с формулами (треугольник, стрелка с adj), кривая, `qx`, дуга `ar`, `v:polyline`, надпись VML в строке |
| grad.docx | градиенты: линейный, трёхцветный под 45°, радиальный, радиальный из угла |
| ch2_combo/bar3d/pie3d/markers.docx | диаграммы: столбцы + график на вторичной оси, объёмные столбцы, объёмная круговая, маркеры |
| wrap.docx | обтекание треугольной картинки по контуру (`wrapTight` + `wrapPolygon`) |
| t19b.docx | картинка с обтеканием, привязанная к странице (x = 12 см, y = 20 см) |
| rev.docx / rev_narrow.docx | исправления двух авторов, перемещения, примечания: выноски (широкое поле) и список в конце (узкое поле) |
| math.docx | формулы: квадратное уравнение, сумма, интеграл, матрица, система, предел, вложенные дроби, корень 3-й степени, групповая скобка, встроенная формула |
