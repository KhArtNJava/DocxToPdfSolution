# Тестовый корпус DOCX

Документы для проверки конвертации DOCX → PDF (эталон — LibreOffice):

| Файл | Что проверяет |
|---|---|
| t1_text.docx | форматирование символов (масштаб `w:w`, рамка `w:bdr`, контур, разрядка…), абзацы (выравнивание, отступы, в т.ч. отрицательные, интервалы, рамки с объединением), табуляция, RTL |
| t2_lists.docx | многоуровневые списки, `lvlJc` (номера справа), маркеры Symbol/Wingdings, startOverride |
| t3_tables.docx | табличные стили с условным форматированием, объединения, вертикальный текст, вложенные таблицы, повтор шапки |
| t4_sections.docx | разделы, колонтитулы (первая/чётная страница), альбомная ориентация, нумерация с 100, колонки, поле PAGE в тексте |
| t5_objects.docx | плавающая картинка с обтеканием, надпись, сноска, ссылка, исправления, формула, буквица |
| t6_lo_index.docx, t7_lo_html.docx | документы, сохранённые LibreOffice (указатели, внешние картинки `r:link`) |
| t8_page.docx | рамка страницы, фон, водяной знак, сетка строк `docGrid`, современный табличный стиль, таблица в колонтитуле |
| t9_bidi_math.docx | иврит/арабский (bidi, формы букв), формулы OMML |
| t10.docx | формат номера страницы (`pgNumType fmt`: римские, буквы), десятичная табуляция, внутренние ссылки на закладки (`w:anchor`), эффекты emboss/imprint/shadow |
| t11.docx | зеркальные поля (`w:mirrorMargins`) |
| t12.docx | элементы `w:sdt`, `smartTag`, `customXml`, `fldSimple`, `w:sym`; позиционная табуляция `w:ptab`; стили и цвет подчёркивания; двойное зачёркивание; ширина таблицы в процентах |

Сгенерировать заново: `python3 gen.py && python3 gen2.py && python3 gen3.py && python3 gen4.py && python3 gen5.py && python3 gen6.py` (нужен python-docx).
Сравнение с LibreOffice: сконвертировать в `ours/` и `lo/`, затем `python3 cmp.py`.
