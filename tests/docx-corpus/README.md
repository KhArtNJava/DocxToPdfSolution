# Тестовый корпус DOCX

Документы для проверки конвертации DOCX → PDF (эталон — LibreOffice):

| Файл | Что проверяет |
|---|---|
| t1_text.docx | форматирование символов (масштаб `w:w`, рамка `w:bdr`, контур, разрядка…), абзацы (выравнивание, отступы, в т.ч. отрицательные, интервалы, рамки с объединением), табуляция, RTL |
| t2_lists.docx | многоуровневые списки, `lvlJc` (номера справа), маркеры Symbol/Wingdings, startOverride |
| t3_tables.docx | табличные стили с условным форматированием, объединения, вертикальный текст, вложенные таблицы, повтор шапки |
| t4_sections.docx | разделы, колонтитулы (первая/чётная страница), альбомная ориентация, нумерация с 100, колонки, поле PAGE в тексте |
| t5_objects.docx | плавающая картинка с обтеканием, надпись, сноска, ссылка, исправления, формула, буквица |
| t6_lo_index.docx, t7_lo_html.docx | документы, сохранённые LibreOffice (указатели, внешние картинки `r:link`) |
| t8_page.docx | рамка страницы, фон, водяной знак, сетка строк `docGrid`, современный табличный стиль, таблица в колонтитуле |
| t9_bidi_math.docx | иврит/арабский (bidi, формы букв), формулы OMML |
| t10.docx | формат номера страницы (`pgNumType fmt`: римские, буквы), десятичная табуляция, внутренние ссылки на закладки (`w:anchor`), эффекты emboss/imprint/shadow |
| t11.docx | зеркальные поля (`w:mirrorMargins`) |
| t12.docx | элементы `w:sdt`, `smartTag`, `customXml`, `fldSimple`, `w:sym`; позиционная табуляция `w:ptab`; стили и цвет подчёркивания; двойное зачёркивание; ширина таблицы в процентах |
| t13.docx | нумерация строк, рамка-абзац `framePr`, узорная заливка, граница `between`, барная табуляция, плавающая таблица `tblpPr`, обрезка/поворот/отражение картинок (gen7.py дописывает `srcRect`/`rot`/`flipH` в XML) |
| t14.docx | нумерация строк: шаг 5, `suppressLineNumbers`, перезапуск на каждой странице |
| t15.docx | общий abstractNum у разных numId, `isLgl`/`lvlRestart`, отступы `start`/`end`, `beforeLines`, цвета выделения, `tblCellSpacing`, формат сносок `footnotePr`, точная высота строки (обрезка), титул с `vAlign=center` |
| t16.docx | нумерация через стиль абзаца, символьный стиль + прямое форматирование, поле HYPERLINK, пустой абзац с крупным маркером, `gridBefore`/`gridAfter`, наследование колонтитулов вторым разделом |
| t17.docx | оглавление на полях HYPERLINK `\l` и PAGEREF, поле REF `\h`, `jc=distribute`, сноска в таблице, картинка в колонтитуле (gen11.py требует img.png) |
| t18.docx | поле переплёта `gutter`, `szCs`/`bCs` для иврита и арабского, `moveFrom`, удалённый знак абзаца, таблица без `tblGrid`, знаки ударения `w:em`, XOR переключаемых свойств стилей, эмодзи, отрицательная позиция |
| t19.docx | длинное слово без пробелов, CMYK JPEG, 16-битный PNG, серый с альфой, таблица `bidiVisual`, фигуры DrawingML (прямоугольник, линия) и VML, картинка с обтеканием в абсолютной позиции страницы (gen13.py; картинки подменяются в архиве вручную) |
| t20_strict.docx | t1_text.docx в формате Strict OOXML (пространства имён purl.oclc.org) — результат должен совпадать с t1 |
| t21.docx | группа фигур `wpg`, произвольный контур `custGeom`, рамка и ссылка у картинки, надписи в строке: вертикальный текст `vert270`, автоподбор высоты, поворот 30° (gen14.py; надписи дописываются в XML) |
| t22.docx | фигуры star5/chevron/heart/plus/homePlate, текст в эллипсе (`anchor=ctr`), градиент, `schemeClr` + `lumMod`, `roundRect adj`, прозрачность и оттенки серого у картинки, `arcTo`, гистограмма (gen15.py) |
| t23.docx | EMF и WMF (векторные, экспорт LibreOffice), TIFF: без сжатия, LZW, Deflate, PackBits, JPEG, G4, G3, 1 бит, палитра, серый, CMYK, RGBA (gen16.py; исходные файлы — в tests/images) |
| t24.docx | EMF/WMF с растром, повёрнутым и жирным текстом (adv.svg → LibreOffice) |
| t22_chart_*.docx | та же диаграмма как круговая, график, горизонтальные полосы с накоплением, области |

Сгенерировать заново: `python3 gen.py && python3 gen2.py && python3 gen3.py && python3 gen4.py && python3 gen5.py && python3 gen6.py && python3 gen7.py && python3 gen8.py && python3 gen9.py && python3 gen10.py && python3 gen11.py && python3 gen12.py` (нужен python-docx).
Сравнение с LibreOffice: сконвертировать в `ours/` и `lo/`, затем `python3 cmp.py`.
