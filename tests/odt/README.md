# OpenDocument Text (ODT)

- `native-features.fodt` — плоский ODT, написанный вручную: стили страниц (титульная → обычная через `next-style-name`,
  чётные/нечётные колонтитулы, альбомная с рамкой и римской нумерацией, возврат с продолжением нумерации), оглавление
  с заполнителями, нумерация заголовков, оформление символов (капитель, индексы, волнистое и точечное подчёркивание,
  двойное зачёркивание, разрядка, фон, прописные, скрытый текст), абзацы (выравнивание, отступы, интервалы, фон, двойная
  рамка, цитата, код), буквица, табуляция (центр, по запятой, справа с точками), сноски и концевая сноска, списки (вложенные,
  продолжение нумерации, начало с 10, заголовок списка, старый режим отступов), таблица (шапка, объединения, высокая строка,
  вложенная таблица), рамки (обтекание справа/слева, без обтекания, врезка с подписью), картинка «как символ», формулы
  MathML, фигуры (прямоугольник с текстом, эллипс с градиентом, линия, смайлик по формулам, многоугольник), разделы с
  колонками и с фоном. Эталон — LibreOffice (`soffice --convert-to pdf`).
- `native-features.odt` — тот же документ, сохранённый LibreOffice как ODT (ZIP).
- `math-objects.odt` — формулы как объекты LibreOffice Math (`Object 1/content.xml`, `Object 2/content.xml`).
- `from-docx-*.odt` — документы из корпуса DOCX (`tests/docx-corpus`), преобразованные LibreOffice в ODT: таблицы, объекты,
  страницы (рамка, фон, водяной знак Fontwork, нижний колонтитул-таблица), фигуры OOXML (`ooxml-non-primitive` с
  `drawooo:enhanced-path`, группы, вертикальный текст в надписи), диаграмма, нумерация (`is-legal`, `num-list-format`).
  Результат сверялся и с LibreOffice, и с конвертацией исходного DOCX (число страниц совпадает у всех 21 документа корпуса).
- `minimal-no-styles.odt` — ODT без styles.xml и без стилей (значения по умолчанию).
- `encrypted.odt` — признак шифрования в манифесте: ожидается сообщение «Документ ODT зашифрован».
