# Плавающие блоки, позиционирование, grid

- `float-split.html` — таблица рядом с float (сужается), длинный текст рядом с float у конца страницы (группа разрывается),
  float выше страницы (разрывается, текст обтекает его на всех страницах); эталон — Chromium.
- `fl.docx`, `fl2.docx` — картинка с обтеканием «вокруг рамки», длинный абзац и таблица; в fl2 группа приходится на конец
  страницы и разрывается (эталон — LibreOffice).
- `grid-abs.html` — absolute в relative-предке (все углы, в т. ч. bottom), grid-template-areas, именованные линии, align-content в сетке и во flex с переносом; эталон — Chromium.

## Отложенный плавающий блок и сноски

- `float-deferred.html` (+ `pic.png`) — картинка `float:left` приходится на низ страницы и не помещается: текст её абзаца
  набирается во всю ширину на этой странице, картинка переходит на следующую, где её обтекают следующие абзацы;
  вторая картинка `float:right` помещается. Эталон — Chromium (та же раскладка).
- `float-deferred-footnotes.docx` — картинка 4,5×12 см с обтеканием «вокруг» в абзаце со сносками: текст абзаца
  со сносками — на первой странице (строки подбираются так, чтобы поместились вместе со сносками), картинка с остатком
  текста — на второй. Раньше группа целиком уходила на вторую страницу, оставляя пустое место.
- `frame-split-footnotes.docx` — длинная рамка-абзац (`w:framePr`, обтекание справа) рядом с текстом со сносками:
  группа разрывается между страницами, первая сноска — внизу первой страницы, вторая — второй.
