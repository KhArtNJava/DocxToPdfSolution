# RTF

- `word-style-features.rtf` — RTF в стиле Word, написанный вручную: кодовая страница 1251 (`\'hh`), Юникод (`\u` + `\uc1`),
  `\upr`/`\ud`, Shift-JIS (`\fcharset128`), Symbol (`\fcharset2`); оформление символов (подчёркивания, зачёркивания,
  индексы, капитель, разрядка, маркер, стили символов, скрытый текст); абзацы (выравнивание, отступы, интервалы, заливка,
  рамки, стиль «Цитата», табуляция с заполнителем); поля HYPERLINK, PAGEREF, PAGE, NUMPAGES; сноски (авто, своя «*»,
  концевая); списки по таблице списков (без `\listtext`), многоуровневые, маркеры Symbol, переопределение начала,
  готовая метка `\listtext`, `\pntext`; таблица (шапка, объединение по вертикали, разные `\cellx`, высокая строка,
  вложенная таблица `\itap2`); фигуры `\shp` (картинка и надпись с обтеканием, прямоугольник с текстом, эллипс,
  стрелка, звезда), картинки PNG/DIB/WMF/обрезанная; исправления; разделы (две колонки, альбомный с римской нумерацией),
  колонтитулы первой/чётных/нечётных страниц.
  Эталон — LibreOffice (`soffice --convert-to pdf`); он сам не выводит часть содержимого (поля HYPERLINK/PAGEREF,
  картинки, фигуры, вложенную таблицу) — их проверяли по смыслу.
- `from-docx-*.rtf` — документы корпуса DOCX, сохранённые LibreOffice в RTF (таблицы, плавающая таблица `\tposxr`,
  объекты, фон страницы, водяной знак, списки). Все 21 документ корпуса дают то же число страниц, что и исходный DOCX,
  кроме случаев, где LibreOffice при экспорте теряет сетку строк.
- `minimal.rtf` — без таблиц шрифтов и цветов; `binary-picture.rtf` — картинка в `\bin`;
  `malformed.rtf` — неизвестные слова/назначения, неверный `\'zz`, `\u` вне диапазона, нет закрывающей скобки.
- `word-math.rtf` — формулы Word `\mmath` (синтаксис Word: `\moMathPara`, `\mf`, `\msSup`, `\mrad`, `\mnary`, `\md`,
  `\mm`, `\mfunc`, `\macc`, `\mlimLow`): отдельные (по центру) и в строке. LibreOffice формулы RTF не читает —
  проверяли по смыслу и по тем же формулам в DOCX.
- `shapes-freeform-groups.rtf` — произвольные фигуры `pVertices`/`pSegmentInfo` (замкнутая ломаная, кривая Безье без
  заливки), группа `\shpgrp` (прямоугольник, эллипс, кривая, надпись) с вложенной группой; запасной результат
  `\shprslt` выводиться не должен. LibreOffice кривые не показывает, вложенную группу ставит в угол.
- `annotations.rtf` — примечания `\annotation` двух авторов (выноски на поле); с `--comments end` — список в конце.
- `line-grid.rtf` — сетка строк `\sectspecifyl\sectlinegrid360` (шаг 18 pt) и абзац `\nosnaplinegrid`.
- `pict-macpict-ddb.rtf` — Mac PICT версии 2 (заливки, рамки пером 3 pt, скруглённый прямоугольник, овалы, дуга 270°,
  многоугольник, линия, текст Helvetica полужирный/курсив, PackBitsRect 8 бит с палитрой, DirectBitsRect 32 бит
  с покомпонентной упаковкой) и версии 1 (рамка, овал, текст, монохромный растр); DDB `\wbitmap` 1 и 24 бит.
  Эталон PICT — импорт тех же файлов `.pct` в LibreOffice.
