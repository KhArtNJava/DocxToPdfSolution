# docx2pdf — конвертер DOCX, ODT, RTF, HTML и MHTML → PDF на чистом C# (.NET 10)

Без сторонних библиотек: используется только BCL (`System.IO.Compression`, `System.Xml.Linq`).
Весь код (чтение DOCX, ODT и RTF, разбор TrueType, вёрстка, генерация PDF) написан с нуля.

## Сборка и запуск

```bash
dotnet build -c Release
dotnet bin/Release/net10.0/docx2pdf.dll document.docx -o document.pdf
dotnet bin/Release/net10.0/docx2pdf.dll *.docx -o out_dir/ --fonts ~/my-fonts
dotnet bin/Release/net10.0/docx2pdf.dll page.html -o page.pdf --page-numbers
dotnet bin/Release/net10.0/docx2pdf.dll saved-page.mhtml -o page.pdf
dotnet bin/Release/net10.0/docx2pdf.dll report.odt -o report.pdf
dotnet bin/Release/net10.0/docx2pdf.dll letter.rtf -o letter.pdf
```

Формат входного файла определяется по содержимому (`{\rtf` → RTF, ZIP с content.xml → OpenDocument Text, ZIP с word/document.xml → DOCX,
XML office:document → плоский ODT (.fodt), MIME-заголовки → веб-архив MHTML, иначе HTML). Опция `--revisions` действует и для ODT и RTF.

Опции для HTML и MHTML (CSS `@page` имеет приоритет): `--page-size A3|A4|A5|Letter|Legal`, `--landscape`,
`--margin <мм>`, `--page-numbers`, `--no-remote` (не загружать http(s)-ресурсы).

## Поддерживается

- Шрифты: встраивание подмножеств TrueType (glyf) и OpenType CFF (.otf: CIDFontType0 + FontFile3/CIDFontType0C, номера глифов сохраняются), кириллица и любой Unicode, синтез жирного/курсива, если нет файла начертания
- Текст: жирный, курсив, подчёркивание (в т.ч. двойное), зачёркивание, цвет, выделение, верхний/нижний индекс, ПРОПИСНЫЕ, скрытый текст
- Абзацы: выравнивание (в т.ч. по ширине), отступы, выступ, интервалы до/после, межстрочный (auto/exact/atLeast), contextualSpacing, заливка, верхняя/нижняя граница, разрывы строк и страниц, pageBreakBefore, keepNext/keepLines, контроль висячих строк
- Табуляция: left/center/right/decimal, заполнители (точки, дефисы, подчёркивание) — оглавления
- Списки: маркированные и нумерованные, многоуровневые (`%1.%2.`), decimal/буквы/римские/русские буквы, startOverride
- Таблицы: сетка, gridSpan, vMerge, границы таблицы/ячеек/стиля, заливка, поля ячеек, vAlign, высота строк, вложенные таблицы, разрыв строки между страницами, повтор строк-заголовков
- Рисунки: inline и anchor (как inline), VML imagedata; масштабирование под ширину колонки
- Разделы: размер и ориентация страницы, поля, nextPage/continuous/evenPage/oddPage, нумерация с заданного номера
- Колонтитулы: default/first/even, поля PAGE и NUMPAGES
- Гиперссылки (кликабельные; цвет — только из стиля, как в Word), метаданные (заголовок, автор)

## Кернинг и переносы (все форматы)

- **Кернинг**: парный кернинг шрифта из GPOS (функция `kern`, PairPos форматы 1 и 2, в т.ч. через расширения) или старой
  таблицы `kern`; учитывается и между буквой и пробелом; вывод в PDF — точными смещениями глифов (TJ), текст остаётся
  поисковым. Включается: DOCX — `w:kern` (для кеглей не меньше заданного, как в Word), ODT — `style:letter-kerning`,
  RTF — `\kerningN`, HTML — по умолчанию (как в Chromium), выключается `font-kerning: none`
- **Автоматические переносы**: алгоритм Лианга по словарям LibreOffice (встроены в программу; русский, украинский,
  белорусский, болгарский, английский США/Великобритании, немецкий, французский, испанский, итальянский, польский,
  португальский, нидерландский, чешский, словацкий, шведский, датский, норвежский, венгерский, греческий, сербский,
  хорватский, словенский, литовский, латышский, эстонский, румынский); язык — из текста (`w:lang`, `fo:language`,
  `\lang`, атрибут `lang`), минимум букв до/после переноса — из словаря или документа.
  DOCX: `w:autoHyphenation`, зона переноса `w:hyphenationZone` (по умолчанию 0,25"), `w:consecutiveHyphenLimit`,
  `w:doNotHyphenateCaps`, запрет в абзаце `w:suppressAutoHyphens`; ODT: `fo:hyphenate`, `fo:hyphenation-remain-char-count`,
  `fo:hyphenation-push-char-count`, `fo:hyphenation-ladder-count`, зона, минимальная длина слова и запрет для прописных
  LibreOffice (`loext:hyphenation-*`); RTF: `\hyphauto`, `\hyphhotz`, `\hyphconsec`, `\hyphcaps`, `\hyphpar`;
  HTML: `hyphens: auto | manual | none` (и `-webkit-hyphens`), `hyphenate-limit-chars` (по умолчанию как в Chromium: слово
  от 5 букв, по 2 буквы с каждой стороны)
- **Мягкие переносы**: U+00AD / `&shy;`, `w:softHyphen`, `\-` — место переноса с дефисом (в HTML отключаются `hyphens: none`)

## DOCX: дополнительно поддерживается

- **Колонки** (`w:cols`: равные и заданной ширины, разделитель, разрыв колонки, балансировка перед непрерывным разделом)
- **Сноски** (внизу страницы с разделителем, нумерация, `footnoteRef`) и **концевые сноски** (в конце документа)
- **Плавающие объекты** (`wp:anchor`): картинки и надписи с обтеканием «вокруг рамки/по контуру» (текст обтекает),
  «сверху и снизу», «без обтекания»/«за текстом» (относительно страницы, полей или абзаца, с выравниванием)
- **Надписи** (DrawingML `wps:txbx` и VML `v:textbox`): фон, рамка, внутренние поля; **WordArt/водяные знаки** (`v:textpath`, поворот, прозрачность)
- **Буквица** (`w:framePr dropCap`) высотой ровно N строк
- **Табличные стили с условным форматированием** (`tblStylePr` + `tblLook`): шапка, итоги, первая/последняя колонка,
  чередование строк и колонок (с размером полос), угловые ячейки
- **Формат номера страницы** (`w:pgNumType w:fmt`): римские (IV, iv), буквы (A, a), русские буквы, `- 5 -`, с ведущим нулём
- **Десятичная табуляция**: на позиции табуляции стоит запятая/точка числа — числа выравниваются в столбик
- **Внутренние ссылки** (`w:hyperlink w:anchor` → `w:bookmarkStart`): переход на страницу закладки внутри PDF
- **Зеркальные поля** (`w:mirrorMargins`): на чётных страницах внутреннее и внешнее поля меняются местами
- **Позиционная табуляция** (`w:ptab`): слева/по центру/справа относительно полей или отступов, с заполнителем
- **Подчёркивание**: цвет (`w:u w:color`), стили thick, dotted, dash, dotDash, wave, wavyDouble, words (без пробелов); двойное зачёркивание
- **Ширина таблицы в процентах** (`w:tblW w:type="pct"`) и предпочтительная ширина в пунктах — колонки масштабируются пропорционально
- **Нумерация строк** (`w:lnNumType`): шаг, начальный номер, расстояние до текста, перезапуск по страницам/разделам или сквозная, `suppressLineNumbers`
- **Плавающие таблицы** (`w:tblpPr`) и **рамки-абзацы** (`w:framePr`) у левого или правого края с обтеканием текстом
- **Картинки**: обрезка (`a:srcRect`), поворот (`a:xfrm rot`), отражение (`flipH`/`flipV`)
- **Узорная заливка** (`w:shd` pct5…pct95, полосы, сетки) — смешение цвета узора и фона
- **Барная табуляция** — вертикальная черта на позиции табуляции
- **Нумерация**: `isLgl` (номера всех уровней арабскими: «Глава I» → «1.1»), `lvlRestart`
- **Нумерация сносок** (`footnotePr`/`endnotePr`): формат (в т.ч. римские, буквы, `chicago` — *, †, ‡, §), начальный номер, перезапуск в каждом разделе
- **Точная высота строки таблицы** (`hRule="exact"`): лишнее содержимое обрезается
- **Интервалы между ячейками** (`tblCellSpacing`): у каждой ячейки своя рамка, внешняя рамка вокруг таблицы
- **Вертикальное выравнивание страницы** (`w:vAlign` раздела): по центру, по нижнему краю, по высоте
- **Интервалы в строках** (`beforeLines`/`afterLines`)
- **Поля-ссылки**: HYPERLINK (внешние и `\l` на закладку), REF/NOTEREF с `\h` — кликабельные ссылки в PDF
- **PAGEREF**: номер страницы закладки вычисляется после разбивки на страницы (оглавления показывают актуальные номера, выравнивание по правому краю сохраняется)
- **Распределённое выравнивание** (`jc="distribute"`): все строки, включая последнюю, растягиваются за счёт промежутков между символами
- **Сложные письменности**: для иврита, арабского, тайского, индийских (и фрагментов с `w:rtl`/`w:cs`) берутся `szCs`, `bCs`, `iCs`, `rFonts w:cs`, как в Word
- **Переключаемые свойства** (b, i, caps, strike…): символьный стиль поверх стиля абзаца работает как XOR (жирный + жирный = обычный)
- **Исправления**: удалённый знак абзаца сливает абзац со следующим; `moveFrom` скрывается
- **Знаки ударения** (`w:em`: dot, comma, circle, underDot) с увеличением высоты строки
- **Фигуры без текста** (DrawingML `prstGeom` и VML `v:rect`/`v:roundrect`/`v:oval`/`v:line`): прямоугольник, скруглённый, эллипс, линия и соединители со стрелками, треугольники, ромб, параллелограмм, шести-/восьмиугольник, блочные стрелки; заливка, контур, пунктир, поворот, отражение
- **Группы фигур** (`wpg`, вложенные группы) с картинками, фигурами и надписями; **произвольные контуры** (`custGeom`: линии, кубические и квадратичные кривые)
- **Надписи**: в строке — как строчный блок (не плавающий), вертикальный текст (`vert`, `vert270`), поворот, автоподбор высоты
- **Картинки**: рамка (`pic:spPr/a:ln`), ссылка на картинке (`a:hlinkClick`)
- **Диаграммы** (`c:chart`): гистограммы (столбцы и полосы; с группировкой, накоплением, 100 %), графики, области, точечные, круговые и кольцевые; заголовок, легенда, сетка, подписи осей и значений, цвета рядов и точек (по умолчанию — акценты темы)
- **Фигуры**: звёзды, шеврон, сердце, плюс, пятиугольник-стрелка, блок-схемы; параметр `adj`; градиентная заливка; дуги `arcTo` в `custGeom`; текст внутри фигуры (эллипс и др.) с вертикальным выравниванием `anchor`
- **Цвета DrawingML**: схема цветов темы, модификаторы `lumMod`/`lumOff`/`shade`/`tint`
- **Картинки**: прозрачность (`alphaModFix`), оттенки серого (`grayscl`, кроме JPEG)
- **Метафайлы EMF и WMF** выводятся векторно (не растром): перья (толщина, пунктир, концы и стыки), кисти (сплошные, штриховка), многоугольники, кривые Безье, эллипсы, дуги, секторы, скруглённые прямоугольники, контуры (BEGINPATH…FILLPATH), обрезка прямоугольником и контуром, режимы отображения (MM_TEXT…MM_ANISOTROPIC), мировые преобразования, текст (шрифт, кодировка, выравнивание, межсимвольные расстояния, поворот, подчёркивание), растры DIB (StretchDIBits, BitBlt и др.)
- **TIFF**: все распространённые варианты сжатия, включая факсовые CCITT G3/G4 и JPEG
- **Формулы (OMML) — двумерная вёрстка**: дроби (в т. ч. вложенные, линейные), индексы и предындексы, радикалы со степенью, суммы/произведения/интегралы с пределами (над/под или справа), растягиваемые скобки (круглые, квадратные, фигурные, модули, угловые), матрицы, функции, акценты (крышка, тильда, вектор, черта), групповые скобки, пределы, системы уравнений, рамки; встроенные формулы — по базовой линии строки
- **Исправления с разметкой** (по умолчанию, как печатает Word; `--revisions final` — итоговый вид): вставки подчёркнуты, удаления зачёркнуты цветом автора, перемещения — двойными линиями, черта изменений на поле
- **Примечания**: подсветка диапазона, выноски на правом поле с пунктирной связью; при узком поле — список «Примечания» в конце с номерами в тексте (`--comments`)
- **Двунаправленный текст по UAX #9**: явные встраивания и переопределения (LRE/RLE/LRO/RLO/PDF, `w:dir`, `w:bdo`), изоляты (LRI/RLI/FSI/PDI), метки LRM/RLM/ALM, правила для чисел и разделителей, зеркалирование скобок; лигатура лам-алеф
- **VML**: произвольные контуры (`path` с `v:shapetype`, `adj` и `v:formulas`; команды m/l/c/x/e/t/r/v/nf/ns/ae/al/at/ar/wa/wr/qx/qy/qb), `v:polyline`; надпись VML в строке — строчным элементом
- **Градиенты** — настоящие шейдинги PDF: линейные (несколько опорных цветов, угол) и радиальные (`a:path` с центром `fillToRect`)
- **Диаграммы**: комбинированные (несколько групп рядов), вторичная ось значений, маркеры графиков и точечных (по символу или по умолчанию), объёмные гистограммы и круговые
- **Обтекание по контуру** (`wrapTight`/`wrapThrough` с `wrapPolygon`) и **обтекание объектов, привязанных к странице/полям**
- **Плавающие блоки (float, DOCX-обтекание)**: таблица рядом с float сужается до свободной ширины; float выше страницы
  остаётся плавающим и разрывается между страницами (рамка «срезается»); группа «float + обтекающий текст» разрывается между страницами;
  если плавающий блок (картинка) не помещается в остаток страницы, текст его группы набирается во всю ширину в этот
  остаток (абзац режется по строке с учётом висячих строк), а сам блок переходит на следующую страницу, где его снова
  обтекают остаток абзаца и следующие абзацы (как в Chromium и Word); группа со сносками разрывается между страницами —
  каждая часть уходит со своими сносками, разрез поднимается, пока часть со сносками не поместится
- **Позиционирование**: `absolute` внутри `relative`-предка — `top`/`bottom`/`left`/`right` относительно рамки предка (высота предка известна по концу его содержимого; если предок переходит на другую страницу — от низа его последней части)
- **Grid**: `grid-template-areas` и `grid-area: имя`, именованные линии (`[a b]`, `имя-start`/`имя-end`, `имя N`), курсор авторазмещения как в CSS; `align-content` (start, end, center, space-between/around/evenly, stretch) в сетке и во flex с переносом; `place-content`
- **Таблицы справа налево** (`w:bidiVisual`): колонки зеркально
- **Strict OOXML** (ISO/IEC 29500 Strict, пространства имён purl.oclc.org)
- **Вариативные шрифты OpenType** (TrueType с gvar и CFF2): именованные экземпляры (Regular, Medium, Bold…) становятся
  начертаниями гарнитуры, полужирный выбирается по оси wght; в HTML числовой `font-weight` (100–900, в т.ч. 450, 550)
  задаёт координату оси напрямую. Шрифт встраивается уже в выбранном экземпляре: для TrueType глифы пересчитываются с
  дельтами gvar (вместе с составными глифами и фантомными точками, ширины — по HVAR или фантомным точкам), CFF2 переводится
  в обычный CID-шрифт CFF с контурами, смешанными по координатам осей
- **Эффекты шрифта** emboss (приподнятый), imprint (утопленный), shadow (тень)
- **Вертикальный текст в ячейках** (`textDirection` btLr / tbRl)
- **Рамки абзацев** со всех сторон, `between`, объединение соседних абзацев с одинаковой рамкой (общая рамка и заливка)
- **Рамка страницы** (`w:pgBorders`, от края или от текста) и **фон страницы** (`w:background`)
- **Сетка строк** (`w:docGrid` type="lines") — высота строк кратна шагу сетки, как в Word
- **Поля PAGE/NUMPAGES** в основном тексте (номер подставляется при отрисовке)
- Выравнивание номеров списка (`lvlJc` right/center), масштаб символов (`w:w`), рамка вокруг текста (`w:bdr`), контурный текст
- Картинки по внешней ссылке (`r:link`, файл рядом с документом)
- **Формулы OMML** — двумерная вёрстка (см. ниже)
  отдельная формула — по центру
- **Справа налево**: иврит и арабский (переупорядочивание bidi по строкам, контекстные формы арабских букв, абзацы `w:bidi`)

Тестовый корпус с генераторами — в `tests/docx-corpus`; документы ODT — в `tests/odt`, RTF — в `tests/rtf`.

## ODT (OpenDocument Text): поддерживается

- **Пакет**: `.odt`, шаблоны `.ott`, плоский XML `.fodt` (картинки в `office:binary-data`); метаданные (заглавие, автор);
  зашифрованные документы и документы других типов ODF (таблицы, презентации) — понятное сообщение об ошибке
- **Стили**: стили абзацев и символов с наследованием, стили по умолчанию, автоматические стили (отдельно для содержимого
  и колонтитулов), размеры шрифта в %, объявления шрифтов (`style:font-face`), стили страниц
- **Текст**: шрифт, размер, насыщенность (в т.ч. числовая — ось wght вариативных шрифтов), курсив, подчёркивание (все виды:
  одинарное/двойное/жирное, точки, штрихи, волна, цвет), зачёркивание (одинарное/двойное), верхний/нижний индекс и смещение,
  капитель, регистр (`fo:text-transform`), разрядка, масштаб, цвет и фон, контур, тень, рельеф, скрытый текст, рамка у текста;
  схлопывание пробелов, `text:s`, табуляция, разрыв строки, ссылки (внешние и на закладки/заголовки)
- **Абзацы**: выравнивание (в т.ч. справа налево), отступы (в т.ч. в %), интервалы до/после и «без интервала между абзацами
  одного стиля», межстрочный интервал (%, точный, минимальный, интерлиньяж), не отрывать от следующего, не разрывать,
  разрывы страниц до/после, фон, рамки (одинарные/двойные, отступы), табуляция (позиции относительно отступа, выравнивание
  по левому/правому/центру/символу, заполнители), буквица (`style:drop-cap`: строки, длина, расстояние)
- **Списки**: маркированные и нумерованные, вложенность до 10 уровней, форматы 1/a/A/i/I/а/А, префиксы/суффиксы, показ
  нескольких уровней («1.2.3»), шаблоны LibreOffice 7 (`loext:num-list-format`), «юридическая» нумерация (`is-legal`),
  начальные номера, продолжение нумерации (`continue-numbering`, `continue-list`), заголовки списков без метки, несколько
  абзацев в пункте, режимы отступов `label-alignment` и старый `label-width-and-position`; нумерация заголовков
  (`text:outline-style`), в т.ч. абзацев со стилем уровня структуры
- **Таблицы**: ширины колонок (абсолютные и относительные, повторы), выравнивание и ширина таблицы, отступы, объединение
  ячеек по горизонтали и вертикали (покрытые ячейки), повторяющиеся строки шапки, группы строк, высота строк (точная и
  минимальная), запрет разрыва строки, фон, рамки и поля ячеек, вертикальное выравнивание, поворот текста, вложенные таблицы,
  таблицы справа налево
- **Страницы**: размер и ориентация, поля, рамка и фон страницы, колонтитулы (высота, отступ, отдельные для чётных страниц
  и первой страницы — `header-left`, `header-first`, стиль первой страницы с `next-style-name`), смена стиля страницы
  абзацем или таблицей (`master-page-name`) с перезапуском нумерации, формат номеров страниц, колонки страницы, нумерация строк
- **Разделы**: колонки (число, промежуток, разделитель, разные ширины) с балансировкой, фон и отступы раздела, скрытые разделы
- **Сноски и концевые сноски**: номер (формат и начальное значение из `notes-configuration`, собственный знак), стили знака
  в тексте и в сноске, висячий номер; концевые сноски — на отдельной странице в конце документа
- **Поля**: номер страницы и число страниц, ссылки на страницу закладки; прочие поля (дата, автор, заглавие, номера рисунков
  и таблиц, переменные) — сохранённым значением; оглавление и указатели — готовым содержимым
- **Исправления** (`text:tracked-changes`): по умолчанию — с разметкой, как в LibreOffice (вставки подчёркнуты, удаления
  зачёркнуты цветом автора, черта на поле), `--revisions final` — итоговый вид
- **Рамки и рисунки**: PNG, JPEG, GIF, BMP, TIFF, EMF/WMF (из нескольких вариантов — первый поддерживаемый, иначе замещающее
  изображение объекта), обрезка `fo:clip` с учётом разрешения картинки, прозрачность, оттенки серого, отражение, поворот;
  надписи (`draw:text-box`) с рамкой, фоном, полями, выравниванием текста по вертикали, вертикальным текстом, подписи рисунков
- **Привязка**: «как символ» (по базовой линии, по центру, с полями), к абзацу/символу/странице; обтекание слева/справа/
  параллельно/оптимальное (плавающий блок), «без обтекания» (объект на своём месте, задетые строки — ниже), сквозное (поверх
  или за текстом); положение по выравниванию или смещению относительно абзаца, полей или страницы
- **Фигуры**: прямоугольник (со скруглением), эллипс, линия, соединитель, многоугольник, ломаная, контур SVG, группы,
  фигуры `draw:custom-shape` — встроенные формы и контуры по формулам (`draw:equation`, `draw:enhanced-path`: все команды,
  дуги, четверти эллипса, дуги OOXML, подобласти `sub-view-size`), заливка (цвет, линейный/осевой/радиальный градиент),
  обводка (цвет, толщина, штрих/точки), стрелки, текст в фигуре (стиль текста фигуры), Fontwork (водяные знаки)
- **Формулы**: объекты LibreOffice Math (MathML во вложенном `Object N/content.xml` или прямо в `draw:object`): дроби,
  корни, индексы, суммы и интегралы с пределами, пределы, скобки, матрицы, акценты; размер — из настроек формулы
- **Диаграммы**: объекты диаграмм (`chart:chart`) по локальной таблице данных: гистограммы (вертикальные/горизонтальные,
  с накоплением, 100 %), линейные, с областями, круговые, кольцевые, точечные, лепестковые; заголовок, легенда, цвета рядов
  и точек, вспомогательная ось, подписи данных

## RTF: поддерживается

- **Формат**: RTF 1.x от Word, WordPad, LibreOffice и др.; разбор в дерево групп с назначениями (`\*`), двоичные данные
  `\bin`, повреждённые и оборванные файлы (недостающие скобки, неизвестные слова и назначения пропускаются)
- **Кодировки**: `\ansi`/`\mac`/`\pc`/`\pca`, `\ansicpgN`, кодовая страница шрифта (`\fcharset`, `\cpg`) — в т.ч.
  двухбайтовые (японский, китайский, корейский), Юникод `\uN` с пропуском замен по `\ucN`, пары `\upr`/`\ud`;
  символы шрифтов Symbol и Wingdings переводятся в Юникод
- **Документ**: таблицы шрифтов, цветов и стилей (стили абзацев и символов с `\sbasedon`), `\defchp`/`\defpap`,
  сведения (`\info`: заглавие, автор, тема), размер бумаги, поля, переплёт, альбомная ориентация, `\deftab`, фон страниц
- **Символы**: шрифт, размер, полужирный, курсив, подчёркивание (одинарное, двойное, точки, штрихи, волна, толстое,
  по словам, цвет), зачёркивание (одинарное/двойное), прописные, капитель, скрытый текст, контур, тень, рельеф,
  верхний/нижний индекс, смещение `\up`/`\dn`, разрядка, масштаб, цвет, фон и выделение маркером, стили символов `\cs`;
  спецсимволы (`\emdash`, `\~`, `\_`, кавычки, пробелы, `\tab`, `\line`, `\page`, `\column`)
- **Абзацы**: выравнивание (в т.ч. справа налево), отступы, интервалы (в т.ч. «авто»), межстрочный интервал
  (множитель, точный, минимальный), не отрывать от следующего, не разрывать, разрыв страницы перед, запрет висячих строк,
  табуляция (по левому/правому/центру/разделителю, заполнители), рамки (одинарные, двойные, точки, штрихи, толщина,
  цвет, отступ, рамка между абзацами), заливка (`\cbpat`, `\shading`)
- **Списки**: готовые метки `\listtext` и `\pntext` (Word 95); без них — по таблице списков (`\listtable`,
  `\listoverridetable`): форматы номеров, многоуровневые шаблоны (`\leveltext`/`\levelnumbers`), начальные номера
  и их переопределение, маркеры, символ после метки, оформление метки
- **Таблицы**: строки `\trowd`…`\row` с разными наборами `\cellx` (общая сетка колонок), отступ и выравнивание,
  высота строки (минимальная/точная), строки-заголовки, запрет разрыва, поля ячеек (с учётом перестановки `\clpadl`/
  `\clpadt` в Word), рамки таблицы и ячеек, заливка, вертикальное выравнивание, поворот текста, объединение по вертикали
  (`\clvmgf`/`\clvmrg`) и горизонтали (`\clmgf`/`\clmrg`), вложенные таблицы (`\itap`, `\nestcell`, `\nestrow`,
  `\nesttableprops`), плавающие таблицы (`\tposx*`, `\tposy`) с обтеканием, таблицы справа налево
- **Разделы**: разрывы (`\sbknone`/`\sbkpage`/`\sbkcol`/чётная/нечётная), размер и ориентация страницы раздела, поля,
  колонки (число, промежуток, разделитель), нумерация страниц (начало, перезапуск, римские, буквенные), вертикальное
  выравнивание, нумерация строк; **сетка строк** документа (`\sectspecifyl`/`\sectspecifycl` + шаг `\sectlinegridN`,
  выключение `\sectdefaultcl`; абзацы с `\nosnaplinegrid` к сетке не привязываются)
- **Формулы Word** (`\mmath`): управляющие слова `\mXxx` разбираются как элементы Office Math (OMML) и выводятся
  двумерной вёрсткой, как в DOCX: дроби, индексы, корни, суммы и интегралы с пределами, скобки, матрицы, функции,
  акценты, пределы, системы уравнений; отдельная формула (`\moMathPara`) — по центру строки
- **Примечания** (`\annotation`): автор (`\atnauthor`), инициалы (`\atnid`), место (`\chatn`), подсветка
  комментируемого фрагмента (`\atrfstart`/`\atrfend`) цветом автора; как в DOCX — выноски на правом поле, при узком
  поле — номера [n] и список «Примечания» в конце (`--comments balloons|end|none`)
- **Колонтитулы**: `\header`/`\footer`, для первой страницы (`\titlepg` + `\headerf`), чётных и нечётных
  (`\facingp` + `\headerl`/`\headerr`), расстояния `\headery`/`\footery`, наследование следующими разделами
- **Сноски**: обычные и концевые (`\ftnalt`), автонумерация (`\chftn`) с форматами и начальными номерами
  (`\ftnnar`, `\aftnnrlc`, `\ftnstart` …), собственные знаки сносок; концевые — в конце документа
- **Поля**: PAGE, NUMPAGES/SECTIONPAGES, PAGEREF (с переходом), HYPERLINK (внешние и на закладки `\l`), REF/NOTEREF \h,
  SYMBOL; прочие — сохранённым результатом; `\chpgn`; закладки `\bkmkstart`
- **Исправления**: `\revised`/`\deleted` с авторами `\revtbl` — по умолчанию с разметкой, `--revisions final` — итоговый вид
- **Картинки** `\pict`: PNG, JPEG, EMF, WMF (`\wmetafile`), DIB (`\dibitmap`), DDB (`\wbitmap`: 1–32 бит,
  `\wbmbitspixel`, `\wbmwidthbytes`), Mac PICT (`\macpict`, QuickDraw 1 и 2 — векторно: фигуры, линии, текст, растры
  с палитрой и прямыми цветами, JPEG в QuickTime); шестнадцатеричные и `\bin`;
  размер `\picwgoal`/`\pichgoal`, масштаб, обрезка `\piccrop*`; `\shppict` (с пропуском `\nonshppict`),
  результат внедрённых объектов `\object` (`\result`)
- **Фигуры** `\shp`: картинка (`pib`), надпись (`\shptxt`: поля, выравнивание по вертикали), прямоугольник,
  скруглённый, эллипс, ромб, треугольники, многоугольники, звёзды, стрелки, линия со стрелками, WordArt (водяные знаки);
  заливка, контур (цвет, толщина, штрих), отражение, поворот; положение по выравниванию (`posh`/`posv`) или смещению
  от страницы, полей, колонки, абзаца; обтекание: вокруг (плавающий блок), сверху и снизу, без обтекания/за текстом;
  **произвольные фигуры** — кривые, ломаные, рисованные линии (`pVertices` + `pSegmentInfo`: moveTo, lineTo, кривые
  Безье, замыкание, без заливки/контура; система координат `geoLeft`…`geoBottom`); **группы** `\shpgrp` (в т.ч.
  вложенные) — дочерние фигуры, картинки и надписи в системе координат группы (`groupLeft`…`groupBottom`, `relLeft`…)
  с поворотом и отражением; запасной результат `\shprslt` — только для объектов, которые вывести нельзя

## HTML: поддерживается

- **Веб-архивы MHTML** (`.mht`, `.mhtml`): «веб-страница, один файл» из Chromium/Edge (в т.ч. стили `cid:…@mhtml.blink`),
  Word и Internet Explorer (`file:///…/имя_files/…`, windows-1251 в quoted-printable, VML-картинки через запасной `<img>`),
  письма multipart/related с картинками `cid:` (вложенные multipart/alternative). Основная часть — по параметру `start`,
  иначе первая text/html; кодировка — из Content-Type части или `<meta charset>`; ссылки (относительные, абсолютные,
  корневые, с `%XX`, с учётом `<base href>`) разрешаются относительно Content-Location страницы и ищутся среди частей
  архива, затем — рядом с файлом. Ресурсы архива используются и при `--no-remote`
- **Фреймы**: `<iframe>` (`src`, `srcdoc`; в MHTML — части `cid:frame-…@mhtml.blink`) и `<frameset>`/`<frame>`
  (`rows`/`cols` в px, % и долях `*`, вложенные наборы, `frameborder`). Документ фрейма разбирается отдельно — со своими
  стилями и `<base>`, картинками из архива, вложенными фреймами (до 8 уровней, фрейм-предок не загружается повторно);
  выводится в рамке размера фрейма (по умолчанию 300×150 px, рамка 2px inset, `width`/`height` из атрибутов или CSS,
  в т.ч. float/absolute) с обрезкой по ней; фон html/body фрейма закрашивает всю область, absolute/fixed-элементы
  документа фрейма позиционируются относительно фрейма. `<frameset>` занимает область страницы, `<noframes>` скрыт.
  Картинка в качестве документа фрейма выводится как картинка
- Кодировки: UTF-8/16 (BOM), `<meta charset>` (в т.ч. windows-1251, koi8-r)
- CSS из `<style>`, `<link rel=stylesheet>` (локальные файлы), атрибута `style`; `!important`
- Шрифт (family/size/weight/style, сокращение `font`), цвет, фон, `text-decoration`, `text-align` (включая justify),
  `text-indent`, `line-height`, `white-space` (pre, nowrap), `text-transform`, `vertical-align` (sub/super)
- Блочная модель: margin (со схлопыванием), padding, фон блока, верхняя/нижняя рамка, `width` + `margin: auto`
- Заголовки, абзацы, `div`, `blockquote`, `pre`, `hr`, `br`, списки `ul/ol/dl` (вложенные, `start`, `type`, `list-style-type`)
- Таблицы: `thead/tbody/tfoot`, `colspan`, `rowspan`, автоподбор ширин колонок по содержимому, `width` в px/%,
  `border`, `cellpadding`, `bgcolor`, рамки и фон ячеек, повтор шапки на каждой странице
- Изображения: файлы, `data:` URI, http(s); `width/height`; `alt` при ошибке
- Ссылки, `page-break-before/after`, `@page { size; margin }`, номера страниц
- **float** `left/right` с настоящим обтеканием текста (строки сужаются рядом с плавающим блоком,
  слово, не поместившееся рядом, опускается ниже), несколько float подряд, `clear`; ширина — из CSS или по содержимому
- **position**: `relative` (сдвиг), `absolute` (относительно ближайшего позиционированного предка или страницы;
  `top/right/bottom/left`, `inset`, ширина по содержимому или из `left`+`right`), `fixed` (на каждой странице),
  `z-index` (отрицательный — под текстом); `sticky` трактуется как `relative`
- **flexbox**: `flex-direction` (row/column/-reverse), `flex-wrap`, `flex-grow/shrink/basis`, `flex`,
  `justify-content` (start/end/center/space-between/around/evenly), `margin: auto`, `align-items`/`align-self`,
  `gap`, `order`; ряды с высоким содержимым разрываются между страницами
- **grid**: `grid-template-columns/rows` (px, %, `fr`, `auto`, `minmax()`, `fit-content()`, `repeat(N | auto-fill | auto-fit, …)`),
  `gap`, `grid-column/grid-row` (`span N`, `a / b`, отрицательные линии), `grid-area` с номерами линий, авторазмещение
- **`grid-auto-flow`**: `row`, `column` (заполнение по столбцам, число строк — из `grid-template-rows`/областей,
  неявные колонки — `grid-auto-columns`), `dense` (дыры заполняются более поздними элементами); `grid-auto-rows`
- **`subgrid`**: `grid-template-rows: subgrid` — дети подсетки встают в строки родителя, поэтому строки соседних
  подсеток (типичные карточки: заголовок / текст / подвал) выравниваются; фон, рамка, отступы и скругление углов
  (`border-radius`, в т.ч. разные радиусы) подсетки рисуются по её области. Собственный `row-gap` подсетки — как в CSS:
  её элементы заходят в промежуток родителя на (gap − свой gap)/2 с каждой стороны (строки соседних обычных элементов
  не меняются), больший промежуток — отступом элементов. `grid-template-columns: subgrid` — дети выравниваются по
  колонкам родителя (и сами влияют на их ширину), собственный `column-gap` подсетки учитывается так же
- **Каменная кладка** по колонкам (`grid-template-rows: masonry`, `display: grid-lanes` с колонками): элемент встаёт в
  колонку с наименьшей занятой высотой (размах `span N`, явная колонка), высоты — по фактической вёрстке; кладка
  разрывается между страницами. По строкам (`grid-template-columns: masonry`, `display: grid-lanes` с
  `grid-template-rows`): элемент шириной по содержимому встаёт в строку с наименьшей занятой шириной (`span N` строк,
  явная строка). **`align-tracks`** / **`justify-tracks`** (start, end, center, space-between/around/evenly, stretch;
  список значений — по дорожкам): выравнивание элементов вдоль каждой дорожки кладки, по высоте (CSS `height`)
  или ширине контейнера
- **Фон, рамка, скругление и отступы flex/grid-контейнера** рисуются одним прямоугольником — в т.ч. под промежутками
  между строками и под местом, распределённым `align-content`
- Блоки с боковыми рамками или заданной высотой выводятся рамкой целиком (с разрывом между страницами)
- **Селекторы**: тег, `.класс`, `#id`, атрибуты (`=`, `~=`, `|=`, `^=`, `$=`, `*=`), комбинаторы (пробел, `>`, `+`, `~`),
  `:nth-child()`, `:nth-last-child()`, `:nth-of-type()`, `:nth-last-of-type()` (`odd`, `even`, `an+b`),
  `:first/last/only-child`, `:first/last/only-of-type`, `:not()`, `:is()`, `:where()`, `:has()`, `:empty`, `:root`,
  `:lang()`, `:link`, `:checked`, `:disabled`; специфичность по стандарту (`:where` — нулевая)
- **`::before` / `::after`** (и `:before`/`:after`): `content` со строками (включая `\201C`, `\A`), `attr()`,
  `counter()`, `counters()`, `open-/close-quote` (кавычки по `lang`: «» для ru), `url()`; псевдоэлементы могут быть
  блочными, flex-элементами, позиционированными. **`::marker`** — цвет, шрифт и содержимое маркера списка
- **`::first-letter`**: первая буква блока вместе с окружающей пунктуацией («, —, …), в том числе внутри вложенных
  элементов и после `::before`; буквица через `float: left` с обтеканием текста; наследует стиль `::first-line`
- **`::first-line`**: граница первой строки определяется вёрсткой — первая строка набирается в своём стиле
  (шрифт, размер, начертание, цвет, капитель, регистр, интервал, фон), остаток абзаца переносится заново обычным стилем
- **Капитель** (`font-variant: small-caps`, `w:smallCaps` в DOCX): строчные — уменьшенными прописными, заглавные — полного размера
- **`line-height` в единицах длины** — по правилам CSS: высота строки равна заданной, лишнее место делится поровну
  над и под текстом (текст центрируется по вертикали, как в браузере)
- **flex/grid/table внутри блоков-рамок, float и absolute** — содержимое раскладывается по правилам контейнера
- **Межбуквенный интервал**: `letter-spacing` в HTML, разреженный/уплотнённый интервал `w:spacing` в DOCX
- **`transform`**: `translate`/`translateX`/`translateY` (в т.ч. в % от размера элемента), `scale`/`scaleX`/`scaleY`,
  `rotate` (deg, rad, grad, turn), `skew`/`skewX`/`skewY`, `matrix()`, цепочки функций; `transform-origin`
  (ключевые слова, длины, %); отдельные свойства `translate`, `rotate`, `scale`. Применяется к блокам, картинкам,
  float, absolute/fixed, элементам flex/grid; на раскладку не влияет (как в браузере), выводится матрицей PDF
- **3D-преобразования**: `rotateX`, `rotateY`, `rotateZ`, `rotate3d`, `translateZ`, `translate3d`, `scaleZ`, `scale3d`,
  `matrix3d`, функция `perspective()`, свойства `perspective` и `perspective-origin` у родителя (точка схода — центр
  контейнера, для flex/grid с учётом положения элемента), `transform-origin` с координатой z, `backface-visibility: hidden`,
  отдельное свойство `rotate: x|y|z угол`. Без перспективы 3D проецируется ортогонально (как в браузере) и выводится
  одной матрицей PDF; с перспективой (проективное преобразование, которого в PDF нет) — кусочно-аффинно: элемент
  делится на сетку плиток (4×4…16×16 в зависимости от силы перспективы), каждая со своей матрицей и обрезкой.
  Текст в таких плитках выводится контурами глифов (извлекаются из таблицы `glyf`), а поверх кладётся один
  невидимый текстовый слой — поиск и копирование работают без дублей, ссылки кликабельны. Содержимое рисуется
  один раз в форму (Form XObject с прозрачностной группой), плитки лишь ссылаются на неё — без швов и с малым размером
- **`transform-style: preserve-3d`** — общая 3D-сцена из вложенных элементов (кубы, перевороты карточек, «парящие»
  слои): матрицы 4×4 накапливаются от корня сцены с учётом положения элементов, перспектива применяется к сцене
  целиком, плоскости сортируются по глубине (алгоритм художника), обратная сторона определяется по ориентации
  спроецированного контура (`backface-visibility: hidden` у граней работает в сцене); `flat` — сплющивание по стандарту;
  грани, повёрнутые ребром к зрителю, не рисуются
- **`border-radius`**, в т.ч. **эллиптические** радиусы: `a b c d / e f g h` (1–4 горизонтальных и 1–4 вертикальных
  значения), `border-top-left-radius: 60px 20px`; проценты — горизонтальные от ширины, вертикальные от высоты
  (`50%` на прямоугольнике — эллипс); слишком большие радиусы уменьшаются пропорционально, как в CSS.
  Применяется к блокам, рамкам-ячейкам, элементам flex/grid,
  float, absolute/fixed, строчные элементы (при переносе скругляются только «внешние» углы), картинки (обрезка
  по контуру, `50%` — круг); рамки любого стиля (сплошная, пунктир, точки, двойная) идут по скруглённому контуру
- **`word-spacing`** — дополнительный интервал между словами (в т.ч. отрицательный)
- **`initial-letter: N [погружение]`** (и `-webkit-initial-letter`) у `::first-letter`: буквица высотой ровно в N строк —
  верх прописной по линии прописных первой строки, базовая линия по строке погружения, обтекание ровно на число строк
  погружения; приподнятая буквица (`3 2`, `raise`) раздвигает текст сверху
- `vertical-align` у картинок в строке: `middle`, `top`/`text-top`, `bottom`/`text-bottom`
- Блоки с фоном и внутренними отступами заливаются целиком (фон под padding), рамка `double` у блоков
- **Счётчики**: `counter-reset`, `counter-increment`, `counter-set` с областями видимости (многоуровневая нумерация)
- **CSS-переменные**: `--имя` (наследуются, задаются в `:root`, классах, `style=""`), `var(--x, запасное)` с вложенностью
- **`calc()`**, `min()`, `max()`, `clamp()` с любыми единицами (px, pt, em, rem, %, …) в любых длинах
- **Рамки у строчных элементов** (`span`, `a`, `code`, `kbd`, `::before` …): `border` любого стиля (сплошная,
  пунктир, точки, двойная) с каждой стороны, фон под `padding`, горизонтальные `margin`, вложенные рамки;
  при переносе фрагмента на другую строку левая рамка рисуется только у начала, правая — только у конца, как в браузерах.
  Элементы flex/grid, float и absolute становятся блочными (CSS blockification)

## SVG (HTML, DOCX, ODT)

SVG выводится в PDF векторно (без растеризации), как в браузерах:

- **Источники**: встроенный `<svg>` в HTML (размер — из атрибутов `width`/`height`, CSS или `viewBox`; без размеров —
  во всю ширину), `<img src="…svg">`, `data:image/svg+xml` (base64 и URL-кодирование), сжатый `.svgz`, картинки SVG
  в ODT (`draw:image`) и DOCX (векторный оригинал `asvg:svgBlip` Office 2016+ вместо растровой копии)
- **Фигуры**: `rect` (со скруглением), `circle`, `ellipse`, `line`, `polyline`, `polygon`, `path` — весь синтаксис
  контуров (относительные команды, гладкие кривые, квадратичные, дуги `A`)
- **Стили**: атрибуты оформления, `<style>` (селекторы тегов/классов/id, потомки и дочерние, специфичность),
  `style=""`, наследование, `currentColor`; CSS документа HTML применяется и к встроенным SVG; цвета — именованные,
  `#rgb[a]`, `#rrggbb[aa]`, `rgb()/rgba()/hsl()`; `opacity`, `fill-opacity`, `stroke-opacity`, `fill-rule`,
  `stroke-width`, `stroke-linecap/linejoin/miterlimit`, `stroke-dasharray/dashoffset`, `display`/`visibility`
- **Системы координат**: `transform` (matrix, translate, scale, rotate с центром, skewX/Y), `viewBox` и
  `preserveAspectRatio` (meet/slice, все выравнивания), вложенные `<svg>`, единицы (px, pt, mm, cm, in, em, %)
- **Повторное использование**: `<defs>`, `<use>` (в т.ч. `<symbol>` с viewBox), `<switch>`
- **Заливки**: линейные и радиальные градиенты (`gradientUnits`, `gradientTransform`, фокус `fx/fy`, наследование
  через `href`, прозрачность остановок), узоры `<pattern>` (`patternUnits`, `patternContentUnits`,
  `viewBox`, `patternTransform`)
- **Обрезка** `clipPath` (userSpaceOnUse/objectBoundingBox, `clip-rule`), **маркеры** (`marker-start/mid/end`,
  `orient="auto"`/`auto-start-reverse`, `markerUnits`)
- **Текст**: `text`, `tspan`, `textPath`; списки `x/y/dx/dy`, `text-anchor`, `dominant-baseline`, `baseline-shift`
  (верхний/нижний индекс), `letter-spacing`, `word-spacing`, `text-decoration`, обводка текста; шрифты — системные
  (serif/sans-serif/monospace → Times New Roman/Arial/Courier New), текст остаётся выделяемым
- **Картинки** внутри SVG: `<image>` с `data:` (растр или вложенный SVG)
- Не поддерживаются: фильтры (`filter`), маски (`mask`), `spreadMethod` reflect/repeat, внешние ссылки в `<image>`/`<use>`, анимация, скрипты, `foreignObject`

## Ограничения

- DOCX: обтекание объекта идёт с одной (более широкой) стороны, а не с обеих; объект с обтеканием, привязанный к странице/полям,
  ставится итеративной перевёрсткой (до 4 проходов), а если его место выше абзаца привязки — выводится без обтекания;
  выноски примечаний — только текст (без ответов и вложенного форматирования), при узком правом поле — список в конце;
  формулы: шрифт Cambria Math заменяется доступным (Caladea/Liberation Serif с запасными для символов), выравнивание систем по «&» не поддерживается;
  bidi — UAX #9 без алгоритма парных скобок (N0); диаграммы — без трёхмерного поворота (rotX/rotY), объёмный вид — косоугольный
- EMF+ (GDI+) без GDI-дубля не разбирается (в «двойных» EMF выводится GDI-часть); в метафайлах не поддерживаются растровые операции (ROP) кроме копирования, кисти-узоры выводятся серой заливкой; TIFF: старый JPEG (сжатие 6) и JPEG в плитках не поддерживаются
- Нет сложного шейпинга индийских письменностей; кернинг — только парный (GPOS PairPos / kern), без контекстного (GPOS тип 8) и без кернинга в тексте справа налево; переносы — по шаблонам словаря (составные слова немецкого и т.п. без особых правил второго уровня, нестандартные переносы с заменой букв — без замены)
- Вариативные шрифты: поддерживаются оси и экземпляры fvar/avar, контуры gvar и CFF2, ширины HVAR; оси, кроме wght (ширина wdth,
  оптический размер opsz и т.п.), остаются в значениях по умолчанию или именованного экземпляра; MVAR (вертикальные метрики) не применяется
- 3D: пересекающиеся плоскости сцены не разрезаются (порядок — по центру плоскости, как алгоритм художника);
  для блоков вне flex/grid точка схода перспективы — центр самого элемента;
  `backface-visibility: hidden` скрывает обратную сторону по стандарту (Chromium при печати её показывает)
- ODT: формулы `draw:equation` с функциями, которых нет в ODF 1.3, считаются нулём; градиенты «квадратный/прямоугольный» —
  как радиальный, штриховки и заливка картинкой — сплошным цветом; Fontwork — обычный текст по размеру фигуры; встроенные
  объекты, кроме формул и диаграмм (OLE, таблицы Calc), — замещающим изображением; текст абзаца, к которому привязан объект
  «без обтекания» со смещением вниз, выводится под объектом, а не над ним; примечания (`office:annotation`) не выводятся
- HTML: нет JavaScript; SVG — без фильтров (`filter`) и масок (`mask`); содержимое фрейма — только первая страница области фрейма (без прокрутки и разрыва между страницами); рамка с разными сторонами (цвет/толщина) при скруглении рисуется прямыми отрезками; элемент с `transform` не разрывается между страницами (выше страницы — выводится без
  преобразования); ссылки внутри преобразованного блока кликабельны по исходной (неповёрнутой) области;
  динамические псевдоклассы (`:hover`, `:focus`) в печати не срабатывают

Примеры: `src/DocxToPdf/samples/sample.docx` → `sample.pdf`, `sample.html` → `sample-html.pdf`,
`layout.html` → `layout.pdf` (float, flex, grid, position), `css-features.html` → `css-features.pdf`
(переменные, calc, ::before/::after, счётчики, :nth-child), `inline-boxes.html` → `inline-boxes.pdf` (рамки внутри строки),
`first-letter-line.html` → `first-letter-line.pdf` (буквицы, `::first-letter`, `::first-line`, капитель),
`transform.html` → `transform.pdf` (повороты, масштаб, наклон, центрирование, штамп),
`radius-spacing-initial.html` → `radius-spacing-initial.pdf` (`border-radius`, `word-spacing`, `initial-letter`),
`transform-3d.html` → `transform-3d.pdf` (3D-повороты, перспектива, backface),
`border-radius-elliptical.html` → `border-radius-elliptical.pdf` (эллиптические радиусы),
`preserve-3d.html` → `preserve-3d.pdf` (3D-куб, переворот карточки, вложенная сцена).
